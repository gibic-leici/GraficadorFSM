# FSM Grapher

A web-based tool for designing Finite State Machines (FSM). Designed for use in education and technical documentation, providing a clean interface for creating, editing, and exporting state diagrams.

Developed by the **GIBIC Group at LEICI Research Institute (UNLP-CONICET)**.

## 🚀 Live Demo
You can access the live tool here: `https://[your-username].github.io/GraficadorFSM/` 

## ✨ Key Features
- **Modern Properties Panel**: Agile, real-time editing of state names, actions, and transition symbols.
- **Advanced Geometry**: Bulbous self-loops and customizable transition anchors for professional-grade diagrams.
- **Dynamic Styling**: Support for per-state sizing (radius) and multi-line text for complex actions.
- **Dark/Light Themes**: A dark mode for workspace comfort and a high-contrast light mode optimized for academic reports and printing.
- **Smart Export**:
  - **PNG**: Exports the graph precisely cropped to its bounding box with a clean margin.
  - **JSON**: Save and load your entire machine state to continue working later.
- **Agile Navigation**: Infinite canvas with right-click panning.

## 🖱️ Interaction Guide

### Mouse Controls
- **Left Click**: Select a state or transition to edit properties.
- **Left Click + Drag**: Move states or adjust transition handles.
- **Right Click + Drag**: Pan the entire canvas.
- **Shift + Click (on state)**: Drag to another state to create a new transition.
- **Alt + Click (on state)**: Set as the machine's Start State.

### Keyboard Shortcuts
- **Delete**: Remove the selected state or transition (safely ignores input fields).
- **Enter (in Properties Panel)**: Add multi-line actions or symbols.
